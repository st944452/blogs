# Shadow Logs

Static GitHub Pages blog for TryHackMe writeups.

## Structure

- `index.html` - landing page
- `blog.html` - blog archive page
- `posts/steel-mountain.html` - sample writeup template
- `styles.css` - shared styling

## Publish on GitHub Pages

1. Push this folder to a GitHub repository.
2. In GitHub, open `Settings > Pages`.
3. Set the source to deploy from the main branch root.
4. Your site will be published automatically.

## Add a new post

1. Copy `posts/steel-mountain.html` to a new file in `posts/`.
2. Change the title, metadata, and content.
3. Add a link to the new file in `blog.html`.
